Como instalar o Suportezap

São 3 passos:

1. Copie o código do Suportezap
2. Abra o código HTML da página onde deseja exibir o botão
3. Cole o código imediatamente antes de </body>

Importante:
• Se instalar o código apenas em uma página, o Suportezap aparecerá somente nela.
• Se instalar em uma área global do site (como Header, Footer ou layout principal), o Suportezap aparecerá em todas as páginas.

Se tiver dúvidas, envie este código para o desenvolvedor do seu site ou use a seção Suporte no menu.
