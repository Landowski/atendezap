Perguntas Frequentes

O que é o Suportezap?
O Suportezap é um widget de atendimento via WhatsApp que você instala no seu site com uma linha de código. Ele distribui automaticamente os visitantes entre seus atendentes usando roteamento, sem você precisar fazer nada manualmente.
Preciso saber programar para instalar?
Não. É só copiar uma linha de código do painel e colar no seu site. Funciona em qualquer plataforma — WordPress, Wix, Shopify, Elementor, HTML puro. Basta abrir o código do seu site e instalar o Suportezap.
Funciona com a API oficial do WhatsApp?
O Suportezap usa os links padrão para abrir o WhatsApp, portanto não precisa de API oficial, de aprovação da Meta ou de número comercial. Funciona com qualquer número de WhatsApp comum. O visitante clica no widget (botão) e cai direto na conversa com o atendente disponível.
Quantos sites e atendentes posso cadastrar?
Sites e atendentes ilimitados em qualquer plano pago. Ideal para agências que gerenciam múltiplos clientes ou empresas com várias equipes de atendimento.
O que acontece quando nenhum atendente está disponível?
O widget some automaticamente do site quando todos os atendentes estão fora do horário configurado. Nada de botão que não responde: o visitante não vê o widget se não tem ninguém para atendê-lo.
Funciona com vários atendentes em um único número de WhatsApp?
Não. Cada atendente utiliza o seu próprio número de WhatsApp. O Suportezap não transforma um único número em atendimento multiusuário. Ele apenas distribui automaticamente os novos contatos do site entre os atendentes cadastrados.
O Suportezap cria chatbot ou responde mensagens automaticamente?
Não. O Suportezap não envia respostas automáticas e não possui chatbot. O sistema apenas direciona o visitante para o WhatsApp do atendente da vez. Você pode configurar uma mensagem pré-preenchida para facilitar o início da conversa.
Posso cancelar quando quiser?
Sem multa, sem burocracia, sem ligar para ninguém. Cancele direto pelo painel a qualquer momento. O acesso continua até o fim do período pago.
